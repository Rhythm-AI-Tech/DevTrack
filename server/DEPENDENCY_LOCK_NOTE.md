The server lockfile was intentionally not retained in this refactor because the environment could not reach the npm registry to resolve the official `openai` SDK package metadata and integrity hash. Run `npm install` from this directory once online to create a complete, reproducible `package-lock.json`, then commit that generated lockfile. The backend uses a lazy SDK import so other API routes can still start while dependencies are being installed, but AI chat requires `openai` to be installed.
